## Install

```bash
pnpm add @jit-compiler/jit
```

## Define a schema

Zod-like builders preserve the resolved output type through every chain.

```ts
import { JIT } from "@jit-compiler/jit/runtime";

const User = JIT.object({
  id: JIT.number().int().positive(),
  name: JIT.string().min(2, "name is too short"),
  email: JIT.string().email().pii("mask"),
  createdAt: JIT.iso.datetime(),
  role: JIT.union(JIT.literal("admin"), JIT.literal("user")),
  tags: JIT.array(JIT.string()).max(8),
});

type User = JIT.Typeof<typeof User>;
```

## Validate

```ts
const isUser = JIT.is(User);
const parseUser = JIT.parse(User);
const safeParseUser = JIT.safeParse(User);

isUser(input); // pure boolean guard — compiled specialized code
parseUser(input); // throws JITValidationError with every issue
safeParseUser(input); // { success, data | issues } — no exceptions
```

## Use the other compiled operations

```ts
const equalUser = JIT.equal(User);
const cloneUser = JIT.clone(User);
const diffUser = JIT.diff(User);
const stringifyUser = JIT.json.stringify(User);

equalUser(a, b); // schema-aware deep equality
cloneUser(a); // static-literal deep clone
diffUser(a, b); // structural diff entries
JIT.update(User).patch({ name: "Ada" }).compile()(a, { name: "Ada" });
stringifyUser(a); // compiled JSON — static keys baked in
JIT.mask(User)(a); // PII-safe copy for logs
```

## Inspect what was generated

Every compiled function carries its own source and cache report:

```ts
const parseUser = JIT.json.parse(User).validate();

parseUser.plan; // immutable execution descriptor
parseUser.explain(); // same descriptor
parseUser.compile(); // optional eager warm-up
```

## Go ahead-of-time

```bash
pnpm jit init      # writes jit.config.ts
pnpm jit doctor    # checks the setup
pnpm jit generate  # emits pure JavaScript and matching .d.ts modules
```

Project-local output uses normal relative `index.js` imports. Output below
`node_modules` becomes a dual ESM/CommonJS package with an exports map. Continue
with [CLI and configuration](/docs/aot/cli-and-config) for discovery, output
layouts and CI, or [generation and tree shaking](/docs/aot/generation-and-tree-shaking)
for standalone and grouped exports.
