## JSON value schema

`JIT.json.value()` creates a schema accepting any
JSON-encodable value:

```ts
const JsonValue = JIT.json.value();

JIT.parse(JsonValue)({
  ok: true,
  items: [1, "two", null],
});
```

Functions, symbols, bigint, undefined, Map and Set are not JSON values.

## Compiled JSON operations

`JIT.json` is a capability namespace. Decoding and validation are deliberately
separate stages that can be composed into one artifact:

```ts
const stringifyUser = JIT.json.stringify(User);
const decodeUserJson = JIT.json.parse(User);
const parseUserJson = decodeUserJson.validate();

const text = stringifyUser(user);
const decoded = parseUserJson(text);
```

`stringify` bakes known object keys and punctuation into generated source.
It avoids runtime reflection and generic replacer callbacks. `parse` is a
direct native `JSON.parse` binding. Adjacent `parse(...).validate()` emits
native parsing followed immediately by the schema-specialized validator.
Runtime compilation prewarms a bounded canonical value for the declared key
order; AOT output remains side-effect free.

## Chunked arrays

```ts
const stringifyUsers = JIT.json.stringifyChunks(JIT.array(User), { chunkBytes: 64 * 1024 });

for (const chunk of stringifyUsers(users)) {
  response.write(chunk);
}
response.end();
```

Chunking bounds the size of intermediate strings but does not make the input
array lazy. Use it when the value already exists in memory but a socket or HTTP
response should receive bounded writes.

## JSON versus codec

JSON is inspectable, ecosystem-friendly and self-describing through field
names. `JIT.binary.encode(schema)` and `.decode(schema)` are compact persisted
wire boundaries. Binary rowsets are process-local analytical memory and must
not be used as a persisted transport.

## Errors

Malformed JSON throws `SyntaxError`. Valid JSON with an invalid shape throws
`JITValidationError` from `parse`. Use
`JSON.parse` plus `safeParse` when both error categories must be returned as
data instead of exceptions.

## AOT

`stringify` and `parse` are independently selectable. AOT output includes only
the selected function and any validation helper it requires.
